# Emad Elmontaser — Portfolio

Personal software engineering portfolio built with Next.js, TypeScript, React, and Tailwind CSS. This repository showcases a selection of projects, skills, and contact information.

Features
- Dark, centered portfolio layout
- Hero with code-style card and profile area
- Featured project cards and project detail pages
- Skills, about, resume stub, and contact sections

Tech stack
- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS

Local development

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Deploy

This project is ready to deploy to Vercel. No environment variables are required for the static portfolio.

Updating projects

Project data lives in `src/data/projects.ts` — update entries and add media under `public/projects/`.

Future improvements
- Add resume PDF
- Add real screenshots and live demos
- Add contact form or email integration
